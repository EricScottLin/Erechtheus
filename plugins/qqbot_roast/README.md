# qqbot_roast — 吐槽 / 电猪插件

安全版「嘴臭」：不带脏字、不做人身攻击的整活吐槽；外加固定表情包 `/电`。

## 用法

| 命令 | 说明 |
|---|---|
| `/骂 @某人` | 随机吐槽一句 |
| `/骂`（回复某条消息） | 吐槽被回复的人 |
| `/骂` | 不指定对象时吐槽发言者自己 |
| `/电 @某人` | 固定发一张「电猪」表情包（也可回复消息） |
| `/梗 ...` | 梗图库管理（**仅超级用户**，私聊使用） |

```
🗣️ 别人是深藏不露，你是深藏不露馅。
—— 对 @某人 说的
```

## 开关

- **默认关闭**，复用 `qqbot_group` 的按群功能开关
- 管理员在群里发 `/开启 骂`、`/开启 电` 打开，`/关闭 骂`、`/关闭 电` 关闭
- 也可以 `@机器人 开启本群骂`

## 梗图库（触发词 → 表情包）

群里**整句**说出触发词，就随机发一张对应的图（句中包含不算，避免误触发）。

**梗图全局共享**：上传一次，任何群只要开了「梗图」功能都能用。

### 上传（仅超级用户，私聊）

```
/梗                        看这条说明
/梗 列表                    查看所有触发词和图片数量
/梗 添加 <触发词>           带一张图，或回复一条带图的消息
/梗 删除 <触发词>           删除该触发词所有图
```

例：私聊发一张图 + `/梗 添加 男的来了`

- 一个触发词可以放多张图，触发时随机抽一张
- 重复上传同一张图会按内容哈希去重
- 数据在 `data/qqbot_roast/memes.json` 与 `data/qqbot_roast/memes/`
- 各群是否生效由按群开关 `meme_reply` 控制（默认关闭）

## 自定义文案

把 JSON 字符串数组放到 `data/qqbot_group/roasts.json`，会和内置文案合并：

```json
["你这操作，我奶奶看了都得摇头", "建议你先把话在脑子里过一遍再发"]
```

## 实现

- `qqbot_roast/features.py` 把 `roast` 注册进 `qqbot_group` 的开关系统（插件未加载时默认关闭）
- 文案池在 `roast.py`，`/骂` 只认 `/` 前缀或 `@机器人`，避免裸「骂」误触发
- 目标支持 @ / 回复 / 不指定（自己）
