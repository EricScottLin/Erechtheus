# qqbot_todo — 待办清单插件

超级用户的 TODO：**自然语言录入**、按优先级查看、完成/放弃、到点提醒，
并且可以把清单**交接给 DSH**（生成交接文件，让 agent 直接开工）。

## 权限

- **仅 `SUPERUSERS` 可用**（默认就是 `1943546421` 那个号）
- 默认只支持**私聊**；群里想用要打开 `qqbot_todo_group_enabled=true`
- 非超级用户在私聊 / 群里发 `/我要做`、`/待办` 会收到一句「只开放给超级用户」，不落任何数据

## 录入

| 写法 | 说明 |
|---|---|
| `我要做 给群管插件加个冷却` | 最常用 |
| `!!我要做 修复 /烟 的冷却 #群管` | `!!`=高优先级，`#标签` 可多个，可组合 |
| `!我要做 紧急上线` | `!` = 紧急 |
| `~我要做 顺手看看文档` | `~` = 低 |
| `/我要做 明确带前缀的` | 显式命令前缀，一律记 |
| `^我要做 …`（QQ 高亮命令） | 支持，高亮命令会被 NoneBot 当成 `我要做` 命令词 + 参数，自动拼回 |

> 不写标记默认是「中」优先级。裸消息里的「我要做点作业」这种明显是聊天，不会记；
> 「@机器人 我要做 xxx」或带 `/` 时一律记。

## 管理（`/待办`，别名 `/todo`）

| 命令 | 说明 |
|---|---|
| `/待办` / `/待办 列表` | 按优先级列未完成 |
| `/待办 列表 完成` / `/待办 列表 全部` | 看已完成 / 全部 |
| `/待办 完成 3`　`我做完了 3`　`/待办 完成 冷却` | 按编号或关键词完成（关键词唯一命中才执行，多命中会让你用编号） |
| `/待办 放弃 3` | 放弃（记录保留，`列表 全部` 能看到） |
| `/待办 删除 3` / `/待办 删除 全部` | 删除已结束的；未结束的会提示先完成或放弃 |
| `/待办 开始 3` | 标记进行中 |
| `/待办 改 3 <新标题>` | 改标题 |
| `/待办 优先级 3 高` | 紧急 / 高 / 中 / 低，或 1~4 |
| `/待办 备注 3 <文字>` | 备注（再发一次不带内容可查看） |
| `/待办 标签 3 #群管 #bug` | 覆盖标签 |
| `/待办 提醒 3 明天 9 点` | 到点私聊提醒 |
| `/待办 记录 3 <DSH任务ID>` | 回填 DSH 任务 ID（联动对账用） |

### 时间写法

`18:00`、`明天 9 点`、`后天下午3点`、`3天后`、`2小时后`、`2026-11-11 20:00`、`11月11日`、`下周三`、`今天`

- 只写「明天 / 3天后」不给钟点：默认当天 **20:00**
- 只写钟点且今天已过：自动顺延到明天

### 容错

QQ 客户端会往每个字之间插空格（`修 复 / 烟 的 冷 却`），插件会：

- 先认已知命令词：`完 成 周 报` → `完成 周报`
- 参数里连续的单字片段合回去：`#群 管` → `#群管`、`修 复` → `修复`
- `完成3`（无空格）→ `完成 3`；`3天后` 不会被误拆
- 长标题 / 备注只合并字间空格，保留 `/烟` 这类英文/斜杠词

## 提醒与每日推送

| 配置 | 默认 | 说明 |
|---|---|---|
| `qqbot_todo_remind_enabled` | `true` | 单条待办到点私聊提醒（每分钟检查） |
| `qqbot_todo_daily_enabled` | `false` | 每天定时把未完成清单私聊推给你 |
| `qqbot_todo_daily_time` | `09:00` | 每日推送时间（服务器时区） |

## 联动 DSH（交接给 agent）

```
/待办 交接 本周要做的事     # 给交接文件起名（会话内生效）
/待办 导出                  # 生成交接文件 + 把全文私聊给你
/待办 导出 完成             # 只导已完成
/待办 导出 全部             # 全部
/待办 导出 json             # JSON 格式
```

生成的文件默认写到 `qqbot_todo_dsh_dir`（**宿主机**路径，留空则只发消息不落文件）：

```ini
# .env.prod
qqbot_todo_dsh_dir=/srv/qqbot/data/qqbot_todo/dsh
```

产物形如 `data/qqbot_todo/dsh/todo_handoff.md`：

```markdown
# 本周要做的事

## ‼️ 紧急
- [ ] #3 紧急上线  <!-- 2026-10-21 -->

## ▪️ 中
- [ ] #2 修复 /烟的冷却  <!-- `#群管` · 2026-10-21 · 提醒 10-21 15:10 -->
    > 记得先看 pigverse 的写法
```

之后在 DSH 里直接说：

> 读 `/srv/qqbot/data/qqbot_todo/dsh/todo_handoff.md`，按里面的事项开始做。

做完后用 `/待办 记录 3 <DSH任务ID>` 回填，便于对账。

## 配置

| 配置项 | 默认 | 说明 |
|---|---|---|
| `qqbot_todo_group_enabled` | `false` | 群里是否可用（默认只私聊） |
| `qqbot_todo_remind_enabled` | `true` | 到点私聊提醒 |
| `qqbot_todo_daily_enabled` | `false` | 每日推送 |
| `qqbot_todo_daily_time` | `09:00` | 推送时间 |
| `qqbot_todo_dsh_dir` | 空 | 交接文件输出目录（宿主机绝对路径） |
| `qqbot_todo_max_active` | `200` | 未完成待办上限 |
| `qqbot_todo_title_max` | `200` | 标题最大长度 |

## 数据

`data/qqbot_todo/tasks.json`（原子写入，坏文件不会让命令崩）：

```json
{
  "next_id": 12,
  "tasks": [
    {
      "id": 11, "title": "给群管插件加个冷却", "status": "open",
      "priority": 2, "tags": ["群管"], "note": "",
      "created_by": "10001", "created_at": 1761100000, "done_at": null,
      "remind_at": 1761186400, "reminded": false,
      "source": {"type": "private", "user_id": "10001"},
      "dsh_task_id": "",
      "history": [{"at": 1761100000, "by": "10001", "action": "create", "detail": ""}]
    }
  ]
}
```

- 状态：`open` 待办 / `doing` 进行中 / `done` 已完成 / `dropped` 已放弃
- 已完成/已放弃最多保留 200 条（超出清最老的），保证 DSH 侧提前做完也能对账
- `data/qqbot_todo/export_done.json` 记录上次导出快照

## 给其他插件用

```python
from nonebot.plugin import require
todo = require("qqbot_todo")

todo.active_tasks()            # 未完成的待办（dict 列表，已按优先级排序）
todo.export_handoff("active")  # 生成交接 Markdown 文本
todo.fresh_tasks()             # 最近 30 天内新建/变更的待办
```
