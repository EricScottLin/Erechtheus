# 荣耀/经济活动想法记录

> 记录待实现或已实现的活动点子，避免丢。当前状态以代码为准。

## 已实现

- **周末倍率**：默认 ×2（`/倍率 周末 N` 可改）
- **节日区间倍率**：2026 国庆 10-01~10-07 ×5，可加任意区间
- **自定义日期倍率**：如生日 `/倍率 2026-11-11 10 生日`
- **倍率 + 取消捕鱼上限**：`/倍率 2026-11-11 20 生日 uncap`
