# 荣耀/经济活动想法记录

> 记录待实现或已实现的活动点子，避免丢。当前状态以代码为准。

## 已实现

- **周末倍率**：默认 ×2（`/倍率 周末 N` 可改）
- **节日日历**（`festivals.py`）：国庆首日/除夕 ×20，传统节日与法定假期每天 ×10，
  西方节日/纪念日 ×5；同一天撞多个节日倍率**相加**（清明×复活节=×15），清单见 [FESTIVALS.md](FESTIVALS.md)
- **节日区间倍率**：可加任意自定义区间（优先级高于日历）
- **自定义日期倍率**：如生日 `/倍率 2026-11-11 10 生日`
- **倍率 + 取消捕鱼上限**：`/倍率 2026-11-11 20 生日 uncap`
- **红包**：bot 主 `/发红包 金额 份数`，群友 `/抢红包`（二倍均值随机拆分，超时退回）
