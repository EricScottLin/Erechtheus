## 根因

1. **分不清"事实"与"可选项"**：该 API 能否用，群里发一条消息试一下就知道；我却去读源码。可选项花掉 5 次以上调用即应放弃。
2. **失败不升级策略**：URL 404 已经证明「路径不存在」，继续换编号不会带来任何新信息。**换参数不是换方法**。
3. **没有预算意识**：没有给探索设定调用上限。
4. **用户信号被忽略**：用户表达不满时，应先停下解释并重新决策，而不是敷衍一句继续。
