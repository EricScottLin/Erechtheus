# 节日与活动倍率清单

> 版本 v1.3 · 2026-10-19 · 数据源：`plugins/qqbot_core/festivals.py`（代码即数据）

荣耀倍率分五类节日 + 四档倍率。查找优先级：

```
自定义日期（/倍率 2026-11-11 10 生日）
  > 自定义区间（/倍率 区间 …）
    > 内置节日日历（本文件）
      > 周末（默认 ×2）
```

## 撞节叠加规则

同一天有多个节日 → **倍率相加**（不叠乘，免得一天刷出天文数字）：

| 日期 | 撞节 | 计算 | 倍率 |
| --- | --- | --- | --- |
| 2026-04-05 | 复活节 + 清明 | 5 + 10 | ×15 |
| 2026-05-04 | 青年节 + 劳动节 | 5 + 10 | ×15 |
| 2026-06-21 | 父亲节 + 端午 | 5 + 10 | ×15 |
| 2026-10-04 | 世界动物日 + 国庆节 | 5 + 10 | ×15 |
| 2026-10-24 | 联合国日 + 程序员日 | 5 + 5 | ×10 |
| 2026-03-14 | 白色情人节 + π Day | 5 + 5 | ×10 |

两个例外：

1. **同一个节日登记两次**（法定假期表 + 农历表都有"端午"）→ 只算一次，取高不叠。
2. **红日替掉同一个假期的普通档**：除夕 ×20 替代春节 ×10，国庆首日 ×20 替代国庆节 ×10。

上限 `MAX_STACK = 60`。

## 特别说明

- **1024 程序员日**：中国程序员节（1024 = 2^10），10-24 与联合国日撞天，合计 ×10。
- **平安夜 ×10 / 圣诞节 ×5**：按当前要求，平安夜算传统档，圣诞节归西方小节。
  想两者一致，把 `SOLAR_FIXED` 里 `(12, 25, "圣诞节", TIER_5, CAT_WEST)` 改成 `TIER_10`。
- **周末不参与叠加**：节日当天撞上周六日，只按节日倍率算（周末 ×2 仅在无节日时生效）。
- **红日默认不取消捕鱼上限**，想放开用 `/倍率 2026-10-01 20 国庆首日 uncap`。
- **法定假期调休**：放假日按通知算，调休上班的周末照常吃 ×2 周末倍数（未单独打标）。
- 农历节日每年日期都变，需按年抄一行；跨年的腊八/小年是次年 1 月，已收进对应公历年的表里。

## 维护方式

```python
# 加一年：在 YEARLY / STATUTORY 里补一段
YEARLY[2027] = [("2027-02-05", "除夕", 20), ...]
STATUTORY[2027] = [("2027-01-01", "2027-01-03", "元旦", 10), ...]
```

- 公历固定节日 → `SOLAR_FIXED`，元组为 `(月, 日, 名称, 倍率, 分类)`
- 某月第 N 个周几 → `NTH_WEEKDAY`；某月最后一个周几 → `LAST_WEEKDAY`
- 黑色星期五 = 感恩节 +1，复活节用 Computus 现算
- 红日 → `RED_DAYS`，`{日期: (显示名, 被替代的节日名, 分类)}`
- 节日名要和法定假期表里的名字一致（`端午` 不是 `端午节`），否则会被当成两个节日叠起来

运行期临时改动不用改代码：`/倍率 2026-12-24 20 平安夜 uncap` 存进
`data/qqbot_core/multipliers.json`，优先级高于日历。

## 命令

```
/倍率            今天倍率 + 近期节日（周末不铺屏）
/倍率 日历 400    未来 400 天的节日表
/签到            签到末尾播报"下一个活动：日期 节日 ×倍率（N 天后）"
```
