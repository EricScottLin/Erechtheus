## 二、功能总览

### 群聊管理 `qqbot_group`

| 命令 | 权限 | 说明 |
|---|---|---|
| `/烟 @用户` | 群管 + bot 是管理员 | 随机禁言 1 分钟 ~ 8 小时 |
| `/禁言 @用户 [时长]` | 同上 | 默认 10 分钟，最长 30 天，支持 `30m`/`2小时`/`1d` |
| `/解禁 @用户` | 同上 | 解除禁言 |
| `/踢 @用户` | 同上 | 移出群聊 |
| `/全体禁言` / `/解除全体` | 同上 | 全员禁言开关 |
| `/撤`（`/撤回`） | 群管 | 撤回机器人自己上一条消息；支持 `/撤` 或 `@机器人 撤` |
| `/盒 @用户`（`/开盒` `/查QQ`） | 所有人 | 返回目标用户的 QQ 号 + **跨插件资产汇总**；支持 @ / 回复 / 直接写 QQ 号 |
| 关键词套餐 | 所有人 | 精致睡眠/午睡/下午茶/晚餐、禁言套餐（牢饭/小黑屋/自闭…）、豪华套餐；默认禁言自己，管理员可指定别人 |
| `/本群功能` | 群管 | 查看本群功能开关 |
| `/开启 <功能>` / `/关闭 <功能>` | 群管 | 按群开关功能 |
| 复读（自动） | — | 连续 3 个不同用户发相同文本/图片 → 跟发一次，60 秒冷却 |

### 表情包与金句 `qqbot_meme`

| 命令/触发 | 权限 | 说明 |
|---|---|---|
| 戳一戳机器人 | 所有人 | 按权重抽：图片（本地 + pigverse）: 金句 = 3:1 |
| `/表情` | 所有人 | 从所有图片来源随机一张 |
| `/表情列表` | 所有人 | 各来源数量、权重、本地文件列表 |
| `/表情添加` | 群管/超管 | 回复图片、先发图 10 分钟内发命令、图文一起发，三种都行 |
| `/表情删除 <序号>` | 群管/超管 | 删除本地表情 |
| `/金句` | 所有人 | 随机**本群**金句，带 `—— 作者` |
| `/金句添加 <内容>` | 群管/超管 | 收录到本群金句库 |
| `/金句同步` | 群管/超管 | 立即拉取群精华（不等定时任务） |

### 帮助

- `/help`、`/帮助`、`/菜单` → picmenu-next 图片菜单（插件列表/详情/模糊搜索）
- `/指令` → 文本菜单（按插件列命令，`/指令 <插件名>` 看详情）

### 资产聚合（/盒）

`/盒` 会遍历所有已注册的资产来源，把用户在各插件里的家底拼到一起：
`qqbot_core` 钱包余额、`qqbot_economy` 签到/鱼竿/钓鱼记录、`qqbot_pigverse` 图鉴/成就/牧场。

其他插件可注册来源：

```python
from nonebot import get_plugin

assets = get_plugin("qqbot_group").module.assets
assets.register_asset_provider("my_plugin", my_assets)  # my_assets(uid) -> list[str]
```

单个来源异常会被跳过，不影响其他来源。

## 三、按群功能开关

```
@机器人 关闭本群视频解析
@机器人 开启本群视频解析
/关闭 复读
/开启 表情包
/本群功能
```

| key | 名称 | 读取方 |
|---|---|---|
| `repeat` | 复读 | `qqbot_group.repeat` |
| `poke` | 戳一戳表情 | `qqbot_meme.poke` |
| `quotes` | 金句 | `qqbot_meme.quote` |
| `meme` | 表情包 | `qqbot_meme.sticker` |
| `box` | 盒 | `qqbot_group.box` |
| `selfmute` | 禁言套餐/精致睡眠 | `qqbot_group.selfmute` |
| `bili_video` | 视频解析 | 桥接 `nonebot_plugin_bilibili` 的 `_GROUP_OFF`（同一份状态） |

其他插件可注册自己的功能：

```python
from nonebot import get_plugin

features = get_plugin("qqbot_group").module.features
features.register_feature("my_feature", "我的功能", default=True)

if not features.is_enabled(group_id, "my_feature"):
    return
```

## 五、实现要点与踩过的坑

- **命令匹配**：NoneBot 的 `on_command` 要求消息首段是文本；`@机器人 命令` 会被适配器先剥掉 @ 段，所以能触发。但 `/撤` 额外加了「必须显式前缀或 `@机器人`」的规则，避免群聊里裸「撤了」误触发。
- **撤回**：用 `Bot._called_api_hook` 记录每次 `send_msg`/`send_group_msg` 返回的 `message_id`（按群），`/撤` 调 `delete_msg`；只记录本次进程启动后的消息，且受 QQ 2 分钟限制。
- **表情发送**：LLBot 与 NoneBot 是**两个容器、文件系统不互通**，本地图片必须用 base64（`MessageSegment.image(bytes)`）发送，`file://` 不可用。
- **群精华**：OneBot v11 **没有精华变更通知**，只能轮询 `get_essence_msg_list`（只有元数据）→ 对每个新 `message_id` 调 `get_msg` 取正文 → 纯文本入库；图片类精华跳过。
- **金句按群隔离**：早期导入的条目没有群号会全群可见，因此做过一次「备份 → 清空 → 按群重导」迁移，现在每条都带 `group_id`。
- **复读**：图片按 QQ 的 `file`（内容哈希名）识别；按**不同用户数**计数，单人连发不触发。
- **picmenu 冲突**：picmenu-next 用 Alconna 独立匹配 `help/帮助/菜单`，与工具箱 `on_command("help")` 冲突，所以把这三个交给 picmenu，文本菜单改名 `/指令`。
- **来源加权**：图片和文本来源按库大小加权（`count` 模式），否则本地 1 张会和 pigverse 41 张五五开。

## 六、测试与验证

- `test_group.py`：**80 项**通过（禁言/踢人/撤回/复读/功能开关/权限/异常提示）
- `test_meme.py`：**43 项**通过（存储/戳一戳/命令/金句/精华同步/来源注册/按群隔离）
- 线上验证过：LLBot 支持 `set_group_ban` / `delete_msg` / `get_essence_msg_list` / `get_msg` / poke 通知；
  群精华实际导入 25 条（10 + 15 按群拆分）；`/本群功能` 与视频解析桥接状态读写正常。
